# 모눈 · MONOON

중학교 수학·과학 상황을 직접 조작하며 탐구하는 한국어 시뮬레이션 플랫폼입니다.

## 실행

Node.js 22 이상에서 실행합니다. 현재 환경에서는 Node.js 24로 검증했습니다.

```sh
npm ci --cache /tmp/math-platform-npm-cache
npm run dev -- --port 5173
```

```sh
npm test       # 기하 계산 검증
npm run build # 배포용 dist 생성
```

## 첫 번째 실험: 중1 수학 / 원과 부채꼴

- 정삼각형, 정사각형, 정오각형, 정육각형, 정팔각형, 직사각형, 직각삼각형, 직각이등변삼각형, 원
- 변의 길이 및 원 반지름을 0.25–20 cm 범위에서 숫자로 입력
- 정다각형의 각 변 입력은 모두 같은 길이로 연동, 직사각형은 가로·세로 독립 입력
- 직각삼각형은 두 직각변 입력과 빗변 자동 계산, 직각이등변삼각형은 같은 두 직각변 입력과 빗변 자동 계산
- 직선 또는 사각형·삼각형·정삼각형·정사각형·정육각형 바깥 둘레에서 구르기
- 그림 속 꼭짓점 직접 클릭 또는 키보드 Enter/Space로 관찰점 선택 (현재 단계 유지)
- 원은 둘레 위 관찰점 A·B·C·D를 선택하고 사이클로이드 궤적 관찰
- 선택한 점의 완료된 단계별 궤적에 회전각 표시 유지 (다음 단계로 넘어가도 보존)
- 점을 바꾸면 해당 점의 궤적과 완료 단계 각도가 함께 갱신되며, 회전 중심인 점은 이동 원호가 없으므로 궤적 각도 표시 생략
- 그림의 회전 중심에 선택한 점을 기준으로 각도 부채꼴 표시, 재생·일시정지·단계·속도 조절
- 설명 카드와 단계별 관찰 기록은 제거하고 누적 이동 거리 등 핵심 수치만 표시

경로 사각형은 16×10 cm, 삼각형은 밑변 16 cm·높이 13 cm, 정삼각형은 한 변 16 cm, 정사각형은 한 변 12 cm, 정육각형은 한 변 8 cm입니다.

다각형은 접점을 중심으로 강체 회전하며 각 단계에서 관찰점의 `회전 반지름 × 회전각(라디안)`을 합산합니다. 원은 변으로 근사하지 않고 실제 원의 중심 이동과 회전을 계산합니다. 직선에서 원 둘레 점의 이동 거리는 사이클로이드의 속력을 해석적으로 적분하며, 원이 경로 모서리를 돌 때는 모서리를 중심으로 한 회전으로 계산합니다. 원이 한 바퀴 구르면 접점에서 출발한 관찰점의 궤적 길이는 `8r`입니다. 화면의 궤적은 표본화해 그리며 거리 계산은 표본 간 직선거리에 의존하지 않습니다.

현재 직선에서 8단계, 도형 둘레에서 최대 24단계를 탐구합니다. 원의 직선 구르기 한 단계는 90도 회전입니다. 다른 학년과 과목은 콘텐츠 추가 예정 상태입니다. 외부 API, 계정, 데이터베이스 또는 비밀키는 필요하지 않습니다.

`npm run test:standalone`으로 단일 HTML의 오프라인 렌더링, 길이 입력, 점 클릭, 원의 궤적, 경로 선택, 재생과 모바일 화면을 검증합니다. Playwright 브라우저를 설치하거나 `CHROMIUM_PATH`로 로컬 Chromium 실행 파일을 지정하세요. 관리형 환경의 file:// 제한 때문에 테스트는 같은 HTML을 오프라인 브라우저 문서에 직접 로드합니다.

## HTML을 직접 열어 실행하기

배포 ZIP을 압축 해제한 뒤 **가장 바깥쪽의 `index.html`**을 더블클릭하세요.
이 파일에는 JavaScript와 CSS가 모두 들어 있어 인터넷 연결이나 Node.js 설치가 필요하지 않습니다.
소스 코드 폴더의 `index.html`은 개발용이므로 직접 열지 말고 위 개발 서버 명령으로 실행하세요.

`npm run build`는 웹 서버 배포용 `dist/index.html`과 직접 실행용 단일 파일 `dist/monoon.html`을 함께 생성합니다.

## 정확한 수식 표시

반지름, 빗변, 누적 이동 거리는 반올림한 소수 대신 π·근호·분수를 유지합니다. 예를 들어 한 변이 3 cm인 정사각형의 점 C를 첫 단계까지 굴리면 이동 거리는 `3π√2/2 cm`입니다. 직사각형 3×2 cm의 대각선은 `√13 cm`, 직각이등변삼각형의 두 직각변이 3 cm이면 빗변은 `3√2 cm`입니다. 일반 삼각형·경로의 회전각에는 필요한 경우 역삼각함수를 유지합니다.

기호식은 입력한 길이와 도형의 정확한 기하 관계에서 생성하며, 화면 그리기용 부동소수 값을 보고 근호나 π를 추정하지 않습니다. 수식은 오프라인에서 MathML로 표시합니다. 재생 진행은 1/100 단계 단위로 설정합니다.

## 두 번째 실험: 중1 수학 / 정다면체 전개도

홈 화면의 **펼치고 접는 정다면체** 또는 `#polyhedra`에서 시작합니다.

| 정다면체 | 면 | 모서리 | 꼭짓점 | 한 꼭짓점에 모이는 면 | 전개도 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 정사면체 | 4 | 6 | 4 | 3 | 2 |
| 정육면체 | 6 | 12 | 8 | 3 | 11 |
| 정팔면체 | 8 | 12 | 6 | 4 | 11 |
| 정십이면체 | 12 | 30 | 20 | 3 | 43,380 |
| 정이십면체 | 20 | 30 | 12 | 5 | 43,380 |

정다면체의 모서리만 잘라서 만드는 전개도를 모두 수록했습니다. 회전하거나 반사해서 같은 전개도는 하나로 세며, 총 86,784종입니다. 번호 입력, 이전·다음, 무작위 선택, 페이지별 미리보기로 전체 목록을 탐색합니다.

접기 정도 슬라이더와 접기·펼치기 애니메이션, 드래그 시점 회전, 확대, 면 번호 및 접는 모서리 표시를 지원합니다. 각 면은 강체이며 공유 모서리를 축으로 회전합니다. SVG에 실제 3D 좌표를 원근 투영하므로 WebGL이나 외부 라이브러리 다운로드 없이 단일 HTML에서도 동작합니다. 중간 접기 순서에서 면 사이의 충돌을 피하는 경로 탐색은 하지 않습니다.

전개도 데이터는 면 인접 그래프의 모든 신장 트리를 열거하고 정다면체의 전체 회전·반사 대칭군으로 중복 제거하여 생성했습니다. 정십이면체·정이십면체는 각각 5,184,000개의 신장 트리에서 43,380개 대표를 얻습니다. `src/data/solids.json`과 `src/data/nets.json`에 메시와 카탈로그가 포함되어 있으며 일반 빌드에는 재생성이 필요 없습니다.

- `npm test`: 모든 86,784종의 면 겹침·평면성·대칭 중복, 구성 요소 수, 대표 전개도들의 공유 모서리·강체 보존·완성 위치, 기존 도형 굴리기 계산 검증
- `npm run test:polyhedra`: 오프라인 브라우저에서 5종 정다면체, 마지막 전개도, 표, 접기·펼치기·3D 조작·모바일·기존 실험 이동 검증
- `python3 scripts/polyhedra/generate.py`: 전체 메시·전개도 카탈로그 재생성 (Python 3 및 g++ 필요)

## 세 번째 실험: 중1 수학 / 자와 컴퍼스 작도

홈 화면의 **자와 컴퍼스 작도 실험실** 또는 `#construction`에서 시작합니다.

- 기본 작도: 길이가 같은 선분 옮기기, 크기가 같은 각 옮기기, 평행선의 작도, 삼각형의 작도
- 삼각형: SSS(세 변), SAS(두 변과 그 끼인각), ASA(한 변과 그 양 끝 각)
- 심화 작도: 선분의 수직이등분선, 각의 이등분선, 수선(직선 밖의 점·직선 위의 점)
- 선분·각 옮기기와 각 이등분선의 입력값, 삼각형의 변과 각 조건을 변경 가능
- 길이 0.5–12 cm, 각도 5–175도; 삼각부등식이나 각의 합 조건을 만족하지 않으면 작도와 재생을 막고 이유 표시
- 각 단계 선택·재생, 이전·다음 단계, 해당 단계 다시 보기, 전체 연속 재생, 일시정지, 0.5–4배속, 진행 막대
- 눈금 없는 자의 이동과 선 긋기, 컴퍼스 벌리기와 간격을 유지한 원호 그리기 애니메이션
- 도구 및 보조선 표시 전환, 완성 시 확인할 수 있는 기하 관계 표시

작도는 원호 교점·현의 길이 옮기기로 각을 복사하며, 눈금 없는 자로 길이나 각도를 측정하지 않습니다. 삼각형과 보조 교점은 입력 조건에서 기하적으로 계산하고 각 단계의 도구·선분·원호가 그 계산 결과에 연결됩니다. 임의의 각 입력은 문제에서 크기가 주어진 각을 뜻하며, 그 각을 처음부터 자·컴퍼스만으로 생성하는 기능은 아닙니다. 수선 및 수직이등분선의 고정 예시는 작도 조건을 만족하는 컴퍼스 간격을 사용합니다.

`npm run test:construction`은 오프라인 브라우저에서 기본·심화 작도, 도구의 실제 위치 변화, 단계별·연속 재생, 입력값과 작도 불가능 조건, 모바일 및 다른 실험 이동을 검증합니다. `npm test`에는 입력 조건·길이·각·수직·이등분·컴퍼스 반지름 보존 검증도 포함됩니다.

작도 실험실의 단계 버튼은 PC 화면에서 보드 오른쪽에 배치됩니다. 화면 높이에 맞춰 보드와 단계 목록을 함께 보여 주며, 작은 모바일 화면에서는 아래쪽 두 열 버튼으로 전환됩니다. 각 단계의 자세한 설명은 현재 단계 카드 및 버튼의 도움말로 확인할 수 있습니다.

## 네 번째 실험: 중2 과학 / 빛의 반사와 굴절

중2 → 과학 → **빛의 반사와 굴절**, 또는 `#optics`에서 시작합니다.

볼록 거울·오목 거울·볼록 렌즈·오목 렌즈를 선택합니다. 레이저 1–7개의 개수와 개별 높이를 바꿀 수 있고, 그림의 광원을 위아래로 드래그하거나 키보드 ↑·↓로 이동할 수 있습니다. 광선의 진행 방향, 법선, 뒤로 연장한 선, 근축 초점을 표시합니다. 렌즈의 굴절률은 1.33·1.5·1.7 중 선택합니다. 기구의 가장자리 밖으로 향하는 광선은 그대로 지나갑니다.

구면과 광선의 교점을 구하고, 거울에는 반사 법칙을 적용하며 렌즈의 두 구면 및 가장자리에는 스넬의 법칙을 적용합니다. 내부에서 전반사가 생기면 굴절 대신 반사시킵니다. 원형 거울의 곡률 반지름은 8, 렌즈 구면의 반지름은 9인 모형이며, 초점 F는 광축에 매우 가까운 광선으로 구한 위치입니다. 구면 수차 때문에 가장자리 광선은 F에 정확히 겹치지 않을 수 있습니다. 광원은 수평 평행광이며 높이는 모형의 상대 좌표입니다. 광선 추적은 기하광학 모형으로 간섭·회절·분산은 다루지 않습니다.

## 다섯 번째 실험: 중2 과학 / 직접 조작하는 불꽃색 실험

중2 → 과학 → **색으로 만나는 불꽃 반응**, 또는 `#flame`에서 시작합니다.

알코올램프는 뚜껑이 닫히고 불이 꺼진 상태에서 시작합니다. 실험 보드 안의 도구와 오른쪽 시료 아이콘을 직접 조작합니다.

1. 램프의 뚜껑을 옆으로 드래그해 엽니다. 뚜껑은 놓은 자리에 머뭅니다.
2. 성냥갑을 클릭해 성냥을 꺼내고, 성냥 머리를 성냥갑의 갈색 마찰면에 드래그해 불을 붙입니다. 성냥갑을 한 번 더 클릭해도 성냥을 그을 수 있습니다.
3. 불붙은 성냥을 램프의 심지에 가져가 점화합니다. 닫힌 뚜껑 위로는 점화되지 않습니다.
4. 왼쪽 도구함에서 핀셋을 드래그해 오른쪽 시료의 결정에 끝을 댑니다. 손을 놓기 전에도 시료를 자동으로 집습니다. 집은 시료를 불꽃 가운데로 드래그하고 잠시 머물면 특징적인 색이 나타납니다.
5. 핀셋을 빼면 기본 불꽃으로 돌아가고 관찰 기록은 유지됩니다.
6. 옆에 놓인 뚜껑을 심지 위로 드래그해 놓으면 소화됩니다. 심지와 떨어진 곳에 놓으면 불이 유지됩니다. 별도의 자동 점화·소화 버튼은 사용하지 않습니다.

핀셋과 성냥은 방향키로도 이동할 수 있고, 도구·시료 버튼은 Enter 또는 Space로 선택할 수 있습니다. 도구 내려놓기와 실험 처음으로를 지원합니다. 초기화할 때 관찰 기록은 유지되며 별도로 비울 수 있습니다. 최근 관찰한 시료와 기준 색을 나란히 비교할 수도 있습니다.

시료는 염화 리튬, 염화 나트륨, 염화 칼륨, 염화 칼슘, 염화 스트론튬, 염화 바륨, 염화 구리(Ⅱ)입니다. 대표 색은 리튬·스트론튬 빨간색, 나트륨 노란색, 칼륨 보라색, 칼슘 주황색, 바륨 황록색, 구리 청록색입니다. 실제 농도·조명·미량 오염의 차이는 재현하지 않는 대표 색 모형입니다.

`npm run test:science`는 광학 실험과 함께 뚜껑 열기, 실제 성냥 드래그·마찰 점화, 열린 심지로 점화, 핀셋으로 일곱 시료 드래그, 불꽃에서 빼기, 뚜껑으로 소화, 비교·관찰 기록, 모바일과 오프라인 동작을 검사합니다. `npm test`에는 점화 순서, 뚜껑에 따른 상태 제한, 핀셋·가열 조건, 소화와 기록 보존 검증도 포함됩니다.

## 작도 보드 확대

설정 패널은 기본적으로 접혀 보드가 넓게 표시됩니다. 위쪽 **작도 설정 열기**로 작도 종류·길이·각도를 조절하고 다시 접을 수 있습니다. 그림은 125%로 시작하며 확대·축소, 드래그 이동, 그림 맞추기를 지원합니다. **보드 전체화면**은 보드와 오른쪽 단계 버튼을 화면에 크게 표시하며 버튼 또는 Escape로 닫습니다. 모바일은 단계 버튼을 아래쪽에 배치합니다.

기본 작도 보드는 전체화면을 켜지 않아도 화면 아래로 길게 확장됩니다. PC에서는 오른쪽 단계 목록이 스크롤 중에도 옆에 유지되며, 모바일 보드의 기본 높이도 늘렸습니다.

## 사용 편의성 점검 및 최적화

- 작도 단계 패널을 PC에서 340 px로 넓히고 글자·도구 아이콘·버튼을 키웠습니다. 현재 단계 설명을 패널에서 펼쳐 볼 수 있고, 재생 위치가 바뀌면 해당 버튼이 목록 안에 보이도록 스크롤합니다. 목록에서 ↑↓·Home·End로 이동하고 Enter로 재생합니다.
- 작도 보드를 선택한 상태에서 Space로 재생·정지, ←/→로 이전·다음 단계를 조작합니다. 기존 확대·축소·드래그 이동·전체화면·입력값 검증도 유지합니다.
- 빈 핀셋 끝이 시료에 닿으면 자동으로 집고, 손을 놓지 않고 불꽃으로 이어서 드래그할 수 있습니다. 실험 도움말과 Esc로 도구 내려놓기를 제공합니다.
- 불꽃색 관찰 기록과 최근 결과, 광학 기구·광원 높이·굴절률 설정은 같은 탭에서 다른 실험을 다녀와도 유지합니다. 외부 저장은 하지 않으며 새로고침하면 초기화됩니다. 불꽃색 실험에 다시 들어갈 때 램프는 꺼지고 뚜껑이 닫힌 상태입니다.
- 안내 문구의 색 대비를 높였습니다. 실험으로 들어가면 상단부터, 탐색으로 돌아오면 실험 목록부터 표시합니다.
- 홈 카드(`src/cards.jsx`)와 각 실험을 분리하고 실험별 지연 로딩을 적용했습니다. 웹 빌드의 초기 JS 엔트리는 약 1.60 MB에서 0.25 MB로 감소했습니다. 페이지 로딩 실패 때 안내와 복귀 동작을 제공합니다.
- 도형 굴리기의 기호식 누적 거리·LaTeX 변환을 캐싱하고 캐시 크기를 제한했습니다. 재생 후 되감기·관찰점 변경의 정확성을 검사합니다.
- 정다면체 미리보기를 메모화하고 회전 행렬 계산의 임시 배열 생성을 줄였습니다. 광학 광선 계산 중복을 제거하고 고정된 거울·렌즈 모양을 재사용합니다.
- 드래그 업데이트를 화면 프레임에 맞춰 모읍니다. 마지막 이동은 놓는 시점에 반영하고, 불꽃 실험에서는 이동 경로를 보존해 빠른 성냥 긋기·점화가 누락되지 않도록 합니다.

웹 배포에는 `dist`의 모든 파일을 함께 배포하세요. `dist/monoon.html`은 모든 실험을 포함하는 단일 오프라인 HTML입니다. `npm run test:web`은 초기 번들 크기, 선택한 실험만 로드되는지, 청크 다운로드 실패 시 복구 안내를 확인합니다. 다섯 가지 오프라인 브라우저 검사도 사용할 수 있습니다.


## 여섯 번째 실험: 중1 수학 / 입체도형 단면 관찰

중1 → 수학 → **잘라서 발견하는 입체의 단면**, 또는 `#sections`에서 시작합니다.

- 정육면체·직육면체·정사면체·삼각기둥·사각뿔·원기둥·원뿔·구의 8가지 입체
- 절단면 위치(−110%–110%), 수평 기준 기울기(0°–90°), 절단 방향(0°–180°) 조절
- 수평·수직·비스듬한 절단 프리셋, 평면 표시 전환, 시점 초기화
- 반투명 3D 입체와 절단면, 단면을 정면에서 보여주는 2D 창과 모양 이름. 다면체는 변·꼭짓점 개수 표시
- 입체를 마우스·터치 드래그하거나 방향키로 돌려 관찰. 시점 회전은 절단 조건을 바꾸지 않음
- 바깥으로 벗어나는 평면, 점·선분에서만 접하는 퇴화 상태 구분

다면체는 실제 모서리와 평면의 교점을 구하고 평면 위의 볼록 껍질로 정렬합니다. 구의 단면은 해석적으로 계산합니다. 원기둥·원뿔의 곡면 윤곽은 192개 방향으로 나눠 그리는 수치 모형이며, 일부 잘린 타원을 완전한 타원으로 표시하지 않도록 분류합니다. 면적·길이의 근삿값을 수치 정답으로 표시하지 않습니다. 절단면 위치 0%는 해당 방향의 양 끝 투영 위치의 중간이며 ±100%는 지지 평면입니다. 원뿔·사각뿔 같은 비대칭 입체에서는 무게중심을 의미하지 않습니다.

`npm run test:sections`는 단독 HTML을 오프라인으로 열어 8가지 입체, 정사각형·육각형·빈 단면, 절단면 조절, 독립적인 시점 회전과 모바일 레이아웃을 검사합니다. `npm test`는 단면 교점의 공면성, 퇴화 상태, 구 단면의 반지름, 대표 단면 모양을 검사합니다.
